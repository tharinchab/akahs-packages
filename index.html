ឬដំឡើងដោយផ្ទាល់Or install it yourself

ជ្រើសរើស distro របស់អ្នក៖Pick your distro:

curl -fsSL https://downloads.akahs.com/akahs.gpg | sudo tee /usr/share/keyrings/akahs.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/akahs.gpg] https://downloads.akahs.com/apt stable main" | sudo tee /etc/apt/sources.list.d/akahs.list
sudo apt update && sudo apt install akahs

Ubuntu 22.04+, Debian 12+, Linux Mint 21+, Pop!_OS 22.04+

sudo dnf config-manager addrepo --from-repofile=https://downloads.akahs.com/rpm/akahs.repo
sudo dnf install akahs

Fedora 37+. RHEL, Rocky និង Alma សូមប្រើ Flatpak។On RHEL, Rocky and Alma, use Flatpak.

sudo zypper addrepo https://downloads.akahs.com/rpm/akahs.repo
sudo zypper refresh && sudo zypper install akahs

openSUSE Leap 15.6+, Tumbleweed

yay -S akahs-bin

flatpak install flathub com.akahs.Chat
